# Правка PDF

Редактор текста в PDF прямо в браузере. Нажмите на любую строку, исправьте текст, и шрифт, размер и цвет подберутся автоматически.

## Возможности

- Правка любого текста на странице: клик, ввод, Enter.
- Автоподбор шрифта по буквам. Каждая буква берётся из оригинального шрифта, вшитого в PDF. Только буквы, которых в файле нет, подставляются из метрически совместимой замены:
  - Arial / Helvetica → Liberation Sans
  - Times New Roman → Liberation Serif
  - Courier New → Liberation Mono
  - Calibri → Carlito
  - Cambria → Caladea
- Автоопределение размера, цвета текста и цвета фона по изображению страницы.
- Точная базовая линия: положение строки берётся по реальным буквам на странице.
- Предпросмотр 1 в 1: после правки страница перерисовывается из настоящего итогового PDF.
- Ручная настройка шрифта, жирности, курсива, размера и цвета; отмена (Ctrl+Z).
- Файл никуда не отправляется: всё работает локально в браузере.

## Запуск

Страница загружает шрифты из папки `fonts/`, поэтому открывать `index.html` двойным кликом нельзя (браузер блокирует загрузку файлов с `file://`). Варианты:

- **GitHub Pages.** Settings → Pages → Branch: `main`, папка `/ (root)`. Через минуту редактор будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.
- **Локально.** В папке проекта выполните `python3 -m http.server 8000` и откройте http://localhost:8000.

## Как это устроено

- [pdf.js](https://mozilla.github.io/pdf.js/) 3.11.174: отрисовка страниц и извлечение текста со шрифтами.
- [pdf-lib](https://pdf-lib.js.org/) 1.17.1 + [@pdf-lib/fontkit](https://github.com/Hopding/fontkit) 1.1.1: запись изменений в PDF.

Библиотеки подключаются с CDN (cdnjs, unpkg).

Исправленный текст записывается поверх оригинала: старая надпись закрашивается цветом фона, новая рисуется на том же месте. Визуально изменения незаметны, но исходный текст остаётся в структуре файла.

## Ограничения

- Сканы и страницы-картинки не редактируются: в них нет текста.
- Текст правится построчно; перенос на новую строку не поддерживается.
- Защищённые паролем PDF нужно сначала разблокировать.

## Лицензии шрифтов

Шрифты в `fonts/` распространяются по SIL Open Font License 1.1. Тексты лицензий лежат рядом со шрифтами.
